# Changelog

All notable changes to Pyrgus Web (https://p.mss.io) are recorded here. The format follows
[Keep a Changelog](https://keepachangelog.com/en/1.1.0/), and versions follow
[Semantic Versioning](https://semver.org/).

## [Unreleased]

## [1.0.2] - 2026-10-09

No changes for visitors. Updates the build and test tools and fixes a security advisory
in one of them (GHSA-68fv-2mgg-jv7q).

## [1.0.1] - 2026-10-09

No changes for visitors. Adds this changelog and the release checks behind it.

## [1.0.0] - 2026-09-28

### Added

- Passwords and secret keys generated entirely in your browser: Password, Custom Password,
  Memorable, PIN, Secret 128 and Secret 256.
- Options for Custom Password (length, symbols) and Memorable (words, separator).
- A dialog about the Pyrgus apps.
- A privacy policy at `/privacy`, covering the site and the apps.
- A support page at `/support`; its form opens your own mail app.
